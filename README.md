# Bank MCQ Quiz

A simple web-based quiz application to test your banking knowledge.

## Features

- Multiple choice questions about banking
- User-friendly interface
- Dark mode toggle
- Progress navigation
- Responsive design

## Technologies Used

- HTML
- CSS

## Usage

1. Open `index.html` in your browser.
2. Enter your details and start the quiz.
3. Navigate through the questions and submit your answers.
